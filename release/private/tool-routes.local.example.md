# Local Tool Routes

复制需要的小节到 `~/.ai/tool-routes.local.md`，填写当前机器的真实值。不要把本文件直接改成包含凭据的 tracked 配置。

## Example project route

- 触发词：`example-project`
- Exact root：`~/Documents/projects/example-project`
- 入口：先读该 root 最近的 `AGENTS.md` / `CLAUDE.md`。

## Example private Git host

- Host：`gitlab.example.com`
- CLI：`glab`
- Repository 必须从当前 remote 或完整 URL 解析，不设置全局默认仓库。
