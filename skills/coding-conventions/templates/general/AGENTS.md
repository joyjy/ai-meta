# 通用工程约定

## Load Order

- 开始实现、评审或验证前，先读当前 repo 最近的 `AGENTS.md` / `CLAUDE.md` / README / CONTRIBUTING；项目规则优先于本模板。
- 本模板只保留跨项目工程底线；测试、Git、语言、CLI、前端等细节读取对应模板或项目文档。

## Scope Control

- 贴近当前 scope 和项目既有模式；避免无依据的过度设计、过度抽象、过度兼容、过度防御和过度测试。
- 优先使用语言、平台和项目已有能力；引入新依赖、框架、配置入口或兼容层前，先确认真实使用方和维护成本。

## Risk Checks

- 涉及 API、鉴权、权限边界、输入输出契约、错误响应或日志变更时，主动检查安全边界、敏感信息泄露和兼容影响；具体规则以项目文档为准。
- 涉及并发、异步、跨线程状态或竞态修复时，主动提醒按成熟并发最佳实践设计和验证；不要把时序假设当作事实。

## Verify

- 完成一个 slice 时，应能说明实际运行过的编译、类型检查、测试、格式化或 lint 命令；未运行时说明原因。
