# 跳板机脚本交付偏好

这是个人手工执行交付约定，不注入团队源码。业务接口、参数和验收由原项目拥有。

## 交接契约

用户在本机复制命令，在目标终端粘贴执行。生成命令不授权 agent 连接服务器或执行业务写操作。

先绑定源文件、目标接口和服务器脚本名。复用本轮已确认的值。控制字段缺失时只问缺失项，不从旧恢复记录推导执行授权。

保留源顺序并去重。长整数 ID 使用文本或精确整数。发现浮点数精度丢失时停止生成名单。

生成前记录总数、批次大小和每批数量。沿用已确认的分批大小。若未指定，批量 ID 名单默认每批不超过 1000 个。

## 默认交付

交付一条本机命令，以 `python3 - <<'PY' | pbcopy` 为外形。命令输出完整的服务器脚本。标明本机复制、服务器粘贴的位置。

名单先用 LZMA 压缩，再用 Base64 编码。服务器脚本用 Python 标准库解码。解码后检查 SHA-256、数量和重复 ID，再写名单文件。

服务器脚本使用带引号的独立 heredoc，并启用 `set -e`。校验失败时禁止执行后续业务命令。外层和内层 heredoc delimiter 必须不同。对路径和参数使用 shell quoting。

同一条剪贴板内容包含名单生成及业务执行命令。若用户只要生成名单，则省略执行。安装脚本只在目标脚本缺失时单独交付。保持用户已确认的脚本名，不添加日期后缀。

本机命令可读取已生成的编码 artifact。交付前检查 exact path 存在。artifact 缺失时从已绑定的原始来源重新生成，不交付失效路径。

每批名单和结果文件使用独立名称。用户说“继续”时交付下一批。用户说一批已完成时记录该批完成，不把提供命令视为执行成功。到最后一批明确说明数量和结束位置。

用户说名单已存储、只需重新调用时，直接交付执行命令。重跑结果使用新文件名，保留前次结果。批处理默认串行，不自动重试。固定间隔沿用任务约定，不凭本约定添加。

## 结果回传

提供在服务器上运行的提取命令。只读取本轮 exact 结果文件，使用每批最新的确认版本。提取失败和结果未知记录，保留 ID、状态及错误信息。用户复制终端输出回传，无需 scp。


## 验收

交付前验证编码往返、名单数量和批次间无重复。用临时目录执行生成部分，禁止验收时调用真实业务接口。检查生成的服务器脚本 shell 语法。说明实际验证范围。
