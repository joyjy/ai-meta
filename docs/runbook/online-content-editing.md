# 在线内容编辑

## 选择编辑方式

如果目标格式支持保真往返，且任务不依赖云端专有语义，优先使用本地临时副本。如果任务依赖实时协作，使用原生在线接口。

权限、评论、协作状态、公式、关联字段、自动化、在线复制和移动依赖云端语义。上述操作使用原生在线接口。

## 本地编辑与回填

1. 导出或下载本地临时副本，记录远端 revision 或修改时间。
2. 在本地副本上读取、分析和批量修改。
3. 回填前核对远端 revision 或修改时间。
4. 源未变化时，只回填最终结果或最小必要差异。

源已变化时，停止覆盖，先处理冲突。不要逐步回填中间草稿。

临时副本按全局规则的临时文件条款清理。
